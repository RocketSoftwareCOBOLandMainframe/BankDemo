# Eclipse Java Bankdemo project

This directory contains a preconfigured Eclipse project for use with the tutorial
[Calling Java from COBOL by Using Enterprise Developer for Eclipse](../../../gettingstarted/eclipse/JavaDemo.md)

The tutorial walks you through creating this project yourself. Import the project
from here instead if you would rather not create it by hand: it links the sample
Java sources from `sources/java`, compiles them to `BankdemoJava/bin`, and supplies
the `ES Java Debug` and `COBOL and Java Debug` launch configurations used in the
debugging section.

The **ES Java Support Library** must still be added to the project's Java build
path, as described in the tutorial, because its location depends on your
Enterprise Developer installation.
